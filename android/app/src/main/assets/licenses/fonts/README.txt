Altyazı yazı tipleri / Caption fonts (res/font/)

All fonts are licensed under the SIL Open Font License 1.1 (see the *-OFL.txt files here).
Source: https://github.com/google/fonts (ofl/inter, ofl/lexend, ofl/notosans, ofl/atkinsonhyperlegiblenext)

The bundled files are static instances (wght 400 and 600) of the upstream variable fonts,
subset to Latin + Latin Extended-A (full Turkish coverage) with fontTools to keep the APK small.
As modified versions they are distributed under the same license.

lexend_regular.ttf, lexend_semibold.ttf            Lexend (The Lexend Project Authors; RFN "RevReading Lexend")
noto_sans_regular.ttf, noto_sans_semibold.ttf      Noto Sans (The Noto Project Authors)
